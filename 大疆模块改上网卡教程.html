🧠 这是什么原理

┌─────────────┐ ┌──────────────┐ ┌─────────────┐
│ 大疆模块 │ ──→ │ 改身份证 │ ──→ │ 移远 EC25 │
│ 2CA3:4006 │ │ AT指令永久改写 │ │ 2C7C:0125 │
│ 大疆私有协议 │ │ + 切 ECM 模式 │ │ iPad 认成网卡 │
└─────────────┘ └──────────────┘ └─────────────┘

模块本质是移远 Quectel EG25-G芯片。大疆给它写了私有 USB 身份证，所以只有大疆设备认。我们发 AT 指令把身份证改成公开的移远 EC25，再切到 ECM 模式（iOS 原生支持的 USB 以太网协议），iPad 就能当有线网卡用了。

📖 手动操作步骤（如果脚本报错）

① 装 WSL2（Windows Linux 子系统）

管理员 PowerShell 里：

wsl --install -d Ubuntu
需要重启电脑。装不了的话先跑：
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

② 装 usbipd-win（USB 透传工具）

管理员 PowerShell 里一条命令：

winget install dorssel.usbipd-win
装完重启电脑。如果 winget 用不了，去 GitHub 下载 .msi 手动装。

③ 更新 WSL 内核（如果 wsl --update 卡住）

下载最新 WSL 安装包（约 246MB）：

curl.exe -L -o wsl-latest.msi "https://github.com/microsoft/WSL/releases/download/2.7.10/wsl.2.7.10.0.x64.msi"

双击安装，然后：wsl --shutdown

内核版本需要 ≥ 5.15 才能 USB 透传。命令 wsl -d Ubuntu -- uname -r 可以看版本。

④ 模块插上，透传进 WSL

先开一个普通 PowerShell 输入 wsl 保持运行。

管理员 PowerShell：

usbipd list                              ← 找到 2CA3:4006 的 BUSID
usbipd bind --busid x-x --force
usbipd attach --wsl --busid x-x

回到 WSL 窗口验证：lsusb 应看到 2ca3:4006

⑤ 发 AT 指令改身份

WSL 里：

apt-get install -y socat
modprobe option
echo 2ca3 4006 | tee /sys/bus/usb-serial/drivers/option1/new_id
echo 'AT+QCFG="usbcfg",0x2C7C,0x0125,1,1,1,1,1,0,1' > /dev/ttyUSB2
echo 'AT+CFUN=1,1' > /dev/ttyUSB2
最后那个 1 就是 ECM 模式。模块重启后会断开 USB 连接（正常），重新 bind + attach 就行。

⑥ 验证 + 完工

lsusb 看到 2c7c:0125 Quectel EC25 → 成功！

拔下模块，插到 iPad USB-C → 设置里出现「以太网」→ IP 地址自动获取 → 上网 ✅
